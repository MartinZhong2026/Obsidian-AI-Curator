很多人问我怎么从零开始学 AI 工程。我的建议是别按清单学，按项目学：

1. 先把 Python、HTTP 和 Git 用熟，能写一个调用 API 的小脚本就够了。
2. 第一个项目：给自己的笔记做一个问答机器人。会遇到切块、向量检索、提示词这些真实问题。
3. 第二步才去学评测：准备 30 个你自己真的会问的问题，每次改动都跑一遍，看哪里变差。
4. 等你能讲清楚为什么某个回答错了（检索没找到？还是模型理解错了？），再去看 Agent、微调这些。

我自己按这个顺序走了三个月，最大的收获是第 3 步：没有评测，你根本不知道改动是变好还是变坏。
