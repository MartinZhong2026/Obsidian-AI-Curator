## Save anything. Read what matters.

AI Curator 1.1.0 makes it easier to decide what deserves your attention and find the useful parts again.

- **Better reading decisions.** The inbox shows the reading payoff, the reason for the verdict, and supporting excerpts when available. Recommendations account for the kind of material you saved.
- **A Toolbox for reuse.** Find source-linked prompts, code, commands, tables, tools, and resources. Copy-ready excerpts are checked against the source text available to the plugin.
- **Incomplete saves get their own view.** Teasers remain provisional. Optional X expansion preserves more of an X Article's structure, and optional GitHub enrichment provides repository facts and README excerpts.
- **A safer upgrade from 1.0.0.** A local repair excludes generated placeholders and rechecks real saves that legacy deduplication hid. Paid re-curation requires approval. Original notes, reading status, and personal text below the marker are preserved.

**Install or upgrade** in Obsidian 1.11.4+ under **Settings → Community plugins**. For manual installation, extract `ai-curator-1.1.0.zip` into `<vault>/.obsidian/plugins/`. For a manual upgrade, replace only the three plugin files and reload Obsidian.

## 简体中文

1.1.0 帮你更快判断哪些收藏值得读，也让有用的素材更容易找到。

- **阅读推荐更有依据。** 收件箱展示阅读收获、判断理由及可用的原文证据，并按内容形态衡量价值。
- **工具箱集中可复用素材。** 汇集带出处的 Prompt、代码、命令、表格、工具和资源。可复制的片段会与可用正文核对。
- **不完整收藏单独展示。** 只有导语的内容保留暂定结论。可选的 X 补全尽量保留长文结构，可选的 GitHub 补充提供项目资料和 README 摘录。
- **从 1.0.0 升级。** 本地修复会排除程序生成的占位笔记，重新检查被旧版去重隐藏的真实收藏。付费重新整理前需确认。原始笔记、阅读状态和标记下的个人笔记均保留。

在 Obsidian 1.11.4+ 的 **设置 → 第三方插件** 安装或更新。也可将 ZIP 解压到 `<仓库>/.obsidian/plugins/`。手动升级时只替换插件三件套，然后重启 Obsidian。
